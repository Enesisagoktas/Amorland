# Amorland

İki oyunculu, 2.5D mobil çiftlik oyunu. Oyuncular aynı çiftliği birlikte yönetir: ekim, sulama, hasat ve kaynak toplama gibi işlerin hepsi sunucuda işlenir, istemci yalnızca oyunun durumunu gösterir.

## Teknolojiler

- İstemci: Unity, C#
- Sunucu: Java, Spring Boot
- Veritabanı: PostgreSQL
- Gerçek zamanlı iletişim: WebSocket

## Durum

Geliştirme devam ediyor. Kaynak kod şimdilik paylaşılmıyor.
